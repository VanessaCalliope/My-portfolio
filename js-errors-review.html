📋 Работа над ошибками (3 задания)

Результаты проверок кода выводятся в консоль браузера (F12 -> Console).

Задание 1: Строгое сравнение типов данных

В чём была ошибка: Использовалось нестрогое сравнение == вместо строгого ===, из-за чего строка "5" приравнивалась к числу 5.

Как нашла: Заметила, что функция возвращала true там, где типы данных должны быть разными.

Задание 2: Фильтрация массива (метод filter)

В чём была ошибка: Забыла написать ключевое слово return внутри функции фильтрации, из-за чего метод возвращал пустой массив.

Как нашла: Вывела результат работы функции в консоль и увидела [] вместо отфильтрованных элементов.

Задание 3: Подсчет суммы чисел в цикле

В чём была ошибка: Переменная для суммы была случайно создана внутри цикла for, поэтому на каждой итерации она сбрасывалась заново.

Как нашла: Проверила код по шагам и увидела, что итоговый результат всегда равен последнему числу.
